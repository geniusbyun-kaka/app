# 새근새근 — 아기 수면 일기

16개월 아기(개월수 자동 계산)를 위한 수면 트래킹 웹앱입니다. 낮잠과 밤잠을 기록하면 데이터가 쌓이고, 주간·월간으로 분석해서 개월수에 맞는 권장 수면 가이드와 비교해 줍니다.

## 기능

- **수면 기록**: 낮잠 / 밤잠을 날짜·잠든 시각·깬 시각으로 기록 (밤잠은 잠든 날짜 기준, 자정 넘김 자동 처리)
- **오늘 현황**: 총 수면 / 밤잠 / 낮잠을 권장 범위와 비교하는 게이지 (부족 / 적정 / 과다)
- **주간·월간 분석**: 일별 스택 차트(밤잠+낮잠)에 권장 범위 밴드 표시, 평균 통계, 자동 분석 문구
  - 총 수면·밤잠·낮잠 평균이 권장 범위 안인지
  - 권장 범위 안에 든 날짜 수
  - 취침 시각 일관성 (편차 분석)
- **가이드**: 생년월일을 저장하면 개월수에 맞는 가이드 자동 적용, 개월수별 권장 수면 표와 수면 팁

## 권장 수면 가이드 (12~17개월 기준)

- 총 수면: 하루 11~14시간
- 밤잠: 10~11시간
- 낮잠: 1.5~2.5시간 (1~2회)

다른 개월수(4~11 / 18~23 / 24~35개월) 구간도 내장되어 있어 아기가 크면 가이드가 자동으로 바뀝니다.

## 사용 방법

`index.html` 하나로 완결된 앱입니다. 별도 빌드나 서버가 필요 없습니다.

- 브라우저에서 `index.html`을 열면 바로 동작합니다 (기록은 브라우저 localStorage에 저장).
- GitHub Pages로 배포하면 폰에서도 사용할 수 있습니다: 저장소 Settings → Pages → 이 브랜치 선택.
- Claude 아티팩트로 발행하면 기록이 서버(artifact db)에 저장되어 기기가 바뀌어도 유지됩니다.

## 참고

권장 범위는 미국수면재단(NSF)·소아과의 일반적인 권장치를 참고한 것으로, 의학적 진단이 아닌 참고용입니다.
