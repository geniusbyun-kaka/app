데이터는 어디서 오나요

GitHub Actions 가 10분마다 Yahoo Finance 에서 나스닥 100 선물(NQ=F)과 원달러 환율(KRW=X) 시세를 받아 이 저장소의 data 브랜치에 저장하고, 이 페이지는 그 파일을 읽어 보여줍니다. Yahoo 자체가 거래소 대비 10~15분 지연이라 화면의 시세는 실제보다 최대 20~25분 정도 늦을 수 있습니다. 페이지는 5분마다 자동으로 새 스냅샷을 확인합니다.

백테스트에 쓰는 일봉은 NQ 선물(2000년~), 나스닥 100 지수(1985년~), QQQ(1999년~), S&P 500(1970년~), SPY(1993년~), 원달러 환율(2003년~)입니다. 원화 기준 백테스트는 환율 데이터가 있는 구간으로 자동으로 맞춰집니다.

배당 재투자를 켜면 ETF 는 분배금을 받은 날 같은 ETF 를 다시 산 것으로 계산한 총수익 가격(Yahoo 의 수정 종가)을 쓰고, 지수는 총수익 지수(나스닥 100 은 XNDX, S&P 500 은 SP500TR)로 바꿔 계산합니다. 끄면 배당을 뺀 가격 수익률만 봅니다. 장기 백테스트에서는 이 차이가 연 1~2%p, 20년이면 총수익에서 수십 %p 차이가 납니다. 선물(NQ)은 가격에 배당 기대치가 이미 반영되어 있어 이 옵션이 없습니다.

전략 설명

  • 바이 앤 홀드 시작일에 전액 매수 후 종료일까지 보유. 다른 전략의 비교 기준입니다.
  • 이동평균 교차 단기 이평이 장기 이평을 위로 뚫으면(골든크로스) 매수, 아래로 뚫으면(데드크로스) 전량 매도 후 현금 보유.
  • 이동평균 필터 종가가 장기 이평 위에 있을 때만 보유, 아래로 내려가면 현금. 큰 하락장을 피하는 대신 잦은 매매로 비용이 생깁니다.
  • RSI 역추세 RSI 가 매수 기준 이하로 떨어지면 매수, 매도 기준 이상으로 오르면 매도. 상승 추세 자산에서는 보유 기간이 짧아 수익을 놓치기 쉽습니다.
  • 적립식 매수 초기 투자금에 더해 매월 첫 거래일에 정해진 금액을 매수. 수익률은 납입 시점을 반영한 내부수익률(연환산)로 표시합니다.

신호는 당일 종가로 계산하고 매매는 다음 거래일 종가에 체결되는 것으로 가정합니다(미래 정보 사용 방지). 선물의 롤오버 비용·증거금·레버리지는 반영하지 않으며, NQ 는 가격 지수처럼 취급합니다.

처음 설정할 때

  1. 저장소 Actions 탭에서 Market data snapshot 워크플로를 한 번 수동 실행(Run workflow)하면 data 브랜치가 생기고 시세가 표시됩니다.
  2. 예약 실행은 기본 브랜치의 워크플로만 동작하므로 이 폴더가 기본 브랜치에 있어야 합니다.
  3. GitHub Pages 로 배포하면 폰에서도 열립니다. 공개 저장소는 Actions 실행이 무료입니다. 60일간 커밋이 없으면 GitHub 이 예약 실행을 자동으로 멈추니 가끔 Actions 탭에서 다시 켜주세요.

유의

이 페이지는 개인 참고용 도구이며 투자 권유가 아닙니다. 지연 시세와 무료 데이터 소스의 특성상 값이 누락되거나 틀릴 수 있으니 실제 주문 전에는 증권사 화면으로 확인하세요. 과거 성과는 미래 수익을 보장하지 않습니다.
